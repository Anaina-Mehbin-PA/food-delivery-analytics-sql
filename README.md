# Food Delivery Analytics using SQL

## Project Overview

This project is a SQL-based Food Delivery Analytics project developed using MySQL.

The project uses a relational database to store and analyze information about customers, restaurants, products, orders, order items, and deliveries.

## Database Structure

The database contains 6 tables:

- Customers – customer details and signup information
- Restaurants – restaurant details and cuisine
- Products – food products, categories, and prices
- Orders – order details, payment methods, and order status
- Order Items – products and quantities included in each order
- Deliveries – delivery time and delivery status

## Dataset

- 100 Customers
- 20 Restaurants
- 60 Products
- 30 Orders
- 60 Order Items
- 30 Delivery Records
